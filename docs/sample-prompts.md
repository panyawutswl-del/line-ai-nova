# Sample Prompts — Nova

## Phase 1 (ใช้ได้ตอนนี้)

**ถาม–ตอบทั่วไป**
- "วันนี้วันที่เท่าไหร่" (ใช้ tool `get_current_datetime`)
- "ช่วยสรุปข้อดีข้อเสียของการ… ให้หน่อย"
- "What's a good way to explain OKRs to my team?"

**ช่วยเขียน / ร่างข้อความ**
- "ช่วยร่างข้อความตอบลูกค้าที่ขอเลื่อนวันเข้าพักหน่อย โทนสุภาพ"
- "แปลประโยคนี้เป็นอังกฤษแบบ business: …"

**ช่วยคิด**
- "มีไอเดียโปรโมชั่น low season สำหรับรีสอร์ทไหม"
- "ช่วยจัดลำดับความสำคัญงานพวกนี้ให้หน่อย: …"

## Phase 2 (ใช้ได้ตอนนี้)

**Memory**
- "จำว่าห้องพักมีทั้งหมด 24 ห้อง" → Pin Memory
- "Remember that my anniversary is March 12"
- "ผมชอบอะไร" / "จำอะไรเกี่ยวกับฉันไว้บ้าง" → semantic search
- "ลืมเรื่องจำนวนห้องพักไปเลย" → ลบ memory

**To-do**
- "เพิ่มงาน โทรหาช่างแอร์ พรุ่งนี้เช้า ด่วนมาก"
- "งานของผมวันนี้" / "มีงานเกินกำหนดไหม"
- "ทำเสร็จแล้ว โทรหาช่างแอร์"

**Reminder** (ส่ง LINE push ตามเวลา)
- "เตือนฉันตอน 6 โมงเย็นให้ส่งรายงาน"
- "เตือนพรุ่งนี้ 8 โมงเช้า ประชุมทีม"
- "มีเตือนอะไรตั้งไว้บ้าง" / "ยกเลิกการเตือนส่งรายงาน"

**Google Calendar** (เชื่อม OAuth ครั้งแรกครั้งเดียว)
- "นัดประชุมพรุ่งนี้ 10 โมง"
- "Schedule meeting tomorrow at 10am at the main office"
- "อาทิตย์นี้มีนัดอะไรบ้าง"

**News**
- "สรุปข่าว AI วันนี้"
- "ติดตามข่าวโรงแรมให้หน่อย" → เข้า Daily Brief ทุกเช้า
- "ติดตามข่าวอะไรอยู่บ้าง" / "เลิกติดตามข่าว AI"

**Daily Brief** — อัตโนมัติทุก 07:00: นัดหมาย + งานวันนี้ + งานค้าง + เตือน + ข่าวที่ติดตาม
